# Data availability

The manifests preserve dataset construction parameters, entity counts, split
counts, direction coverage, exclusions, and source paths. Generated JSONL and
raw zsRE files are intentionally excluded from this GitHub snapshot.

The final end-to-end holdout is identified by SHA-256:

```text
e57e8675f100eb8b9918082f6fd2069d07f3b9e937ae3349569e0ab1d8c12d85
```

It contains 24,000 directed examples from 4,000 entities, with six candidate
passages per example.
